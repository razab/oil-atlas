# Нефть и газ — карта связей

[Открыть полноэкранный атлас](https://razab.github.io/oil-atlas/)

Статический сайт на русском языке, без серверной части и сторонних запросов при просмотре. Карта занимает всё окно. Таблиц и длинной страницы нет: выбранная страна, её поставщики и покупатели, объёмы и энергетические объекты показаны на карте и в небольших карточках поверх неё.

## Как пользоваться

- Выбрать страну на карте или через поиск.
- Переключить сырую нефть, готовый автомобильный бензин, дизель/дистилляты, трубопроводный газ или СПГ.
- Выбрать поставщиков, покупателей или оба направления. По умолчанию подписаны 9 крупнейших связей; кнопка «Все связи» добавляет остальные.
- Нажать на линию или подпись: откроются продукт, объём, год, источник и определение показателя. Из этой карточки можно перейти к стране-партнёру.
- Для США нажать «Где именно»: видны штаты с объёмами добычи, четыре крупных нефтяных бассейна и восемь экспортных терминалов СПГ. Для Франции показаны три терминала Elengy и приёмный узел Franpipe; это часть её инфраструктуры, не полный список.
- В списке слоёв выбрать общий нефтяной баланс, производство, спрос или запасы. Кнопка − сворачивает сведения о стране, ⛶ включает системный полноэкранный режим.

Выбор страны, топлива, слоя, направления, всех связей и объектов сохраняется в адресе. Старые адреса первой версии переводятся к карте поставщиков выбранной страны.

## Данные и точные границы

Срез собран 2 октября 2026 года. Это опубликованные годовые данные, не сегодняшний поток и не трекинг судов. В обработанном графе 702 связи: 239 сырой нефти, 87 бензина, 90 дистиллятов, 244 СПГ и 42 трубопроводного газа. Связи могут соединять страны и явно подписанные региональные группы. Их нельзя интерпретировать как полное покрытие торговли каждой страны.

**США, нефть и нефтепродукты — EIA, 2025.** Национальные таблицы импорта по происхождению и экспорта по назначению. Исходные тысячи баррелей за год делятся на 365: на карте тысячи баррелей в сутки. Готовый бензин — `Finished Motor Gasoline`, без отдельного суммирования компонентов для смешения. Дистилляты — `Distillate Fuel Oil`, включая дизель и отопительное топливо.

Для выбранного топлива в США отдельно показан внутренний выпуск и использование из годовой таблицы EIA. Для сырой нефти использование — **вход на НПЗ**, а не конечное потребление сырой нефти. Для бензина и дистиллятов выпуск — производство НПЗ и блендеров, использование — `product supplied`, оценка внутреннего спроса. Добыча по штатам включает конденсат. Данные штатов не складываются с пересекающими их бассейнами. Потребление по штатам пока не загружено.

**Франция, импорт сырой нефти — INSEE/SDES, предварительные данные 2025.** 45,9 млн тонн полного импорта; отдельно опубликованные семь поставщиков дают 36,5 млн тонн, 79,5%. Остаток не распределён по странам. Страна происхождения — **страна добычи**, не страна последней отгрузки. Категория включает конденсаты и другое сырьё для НПЗ. Поэтому связь США → Франция в этом наборе отличается от экспортной серии EIA. При выборе Франции используется её собственная серия; при выборе США — американская. Эти две оценки не суммируются.

**Газ — Energy Institute Statistical Review 2026, 2025.** Отдельные матрицы трубопроводной торговли и СПГ в миллиардах м³ за год. Строки — назначения, столбцы — происхождение. СПГ включает реэкспорт. Сводные строки исключены, региональные группы не распределены по государствам. В трубопроводной матрице нет отдельной Франции; объём ЕС ей не присваивается. Franpipe показан как инфраструктурная связь Норвегия → Франция, без годового объёма.

**Другие связи сырой нефти — EI Statistical Review 2025, матрица 2024**, млн тонн в год. Они содержат страны и регионы, без полного странового разбиения. Старые региональные связи США заменены национальными данными 2025. Бензин и дистилляты вне торговли с США пока не покрыты.

**Общие показатели нефтяных жидкостей — EI 2026, год 2025**, дополненные EIA crude + NGPL для небольших производителей. 215 современных стран/территорий; сопоставимое производство и спрос есть для 76. Производство включает сырую нефть, конденсат, нефтяные пески и NGL, исключает биотопливо и прирост объёма переработки. Спрос EI исключает биотопливо. Разница производства и спроса **не равна фактическому чистому экспорту**. Для стран без отдельных показателей выбранного нефтепродукта карточка явно показывает общий контекст нефтяных жидкостей.

**Запасы — OPEC ASB 2025, конец 2024**, таблица 3.1, 41 страна. Условные годы = доказанные запасы сырой нефти / годовой спрос на все нефтяные жидкости. Это грубое отношение разных категорий, не прогноз исчерпания. Для Канады срок не рассчитан: в запасах OPEC исключены нефтяные пески.

Серый или «нет данных» означает неизвестный показатель, не ноль. Линии торговли не восстанавливают реальные рейсы, места промежуточной перевалки и конкретные трассы. Нефтяные таблицы не разделяют объёмы по видам транспорта. Точки бассейнов обозначают районы, не точные границы месторождений. Терминалы расположены приблизительно; национальные торговые потоки не распределены по терминалам.

## Воспроизводимость и проверки

`data/snapshot.json` — общий нефтяной срез; `data/connections.json` — связи, собственные показатели топлива США, газовые показатели и объекты. Исходные HTML EIA/INSEE сохранены в `data/raw`, их SHA-256 и границы находятся в источниках графа. Матрицы EI кешируются в исходных workbook; версии и фиксированные SHA-256 описаны в `scripts/build_data.py` и `data/raw/provenance.json`. Страновой набор отделён от графа, чтобы региональные значения не превращались в придуманные национальные.

Для пересборки нужен Python с openpyxl и исходные workbook в `data/raw`. Первый набор можно восстановить скриптом `build_data.py`, проверяющим хеши загружаемых книг.

```sh
python3 scripts/build_connections.py --canary
python3 scripts/test_connections.py
# Проверить canary локально и после публикации, затем:
python3 scripts/build_connections.py
python3 scripts/test_data.py
python3 scripts/test_connections.py
```

Для временной локальной проверки сайт обслуживается обычным статическим HTTP-сервером. UI smoke: `node scripts/smoke.cjs URL`, пакет Playwright задаётся через `PLAYWRIGHT_PACKAGE`; используется установленный Chrome. `EXPECT_CANARY` и `EXPECT_FLOWS` проверяют точные границы опубликованной версии. Повторная сборка графа с кешированными входами даёт тот же JSON побайтно.

Публикация — GitHub Pages через `.github/workflows/pages.yml`. В публичный артефакт попадают только интерфейс, обработанные данные, геометрия и vendor; исходные HTML и workbook не публикуются на сайт. История, автообновление и точные маршруты отдельных грузов пока не реализованы.
