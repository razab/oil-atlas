# Нефтяной атлас

[Открыть карту](https://razab.github.io/oil-atlas/)

Статическая интерактивная карта на русском языке. Без сервера, платных API, сторонних запросов при просмотре и внешних CDN. GitHub Pages публикует только HTML/CSS/JS, карту и обработанный срез.

Основной срез: производство и потребление Energy Institute Statistical Review 2026 за **2025 год**. Если страна отсутствует в таблице производства EI, используется сумма добычи сырой нефти с конденсатом и газовых жидкостей EIA за тот же год. Производство исключает биотопливо и прирост объёма при переработке. Спрос EI также исключает биотопливо. Источник производства указан в карточке.

Запасы: **конец 2024**, OPEC ASB 2025, таблица 3.1, печатная страница 22. Торговля: **2024**, EI Statistical Review 2025, матрица `Oil - Inter-area movements`, млн тонн/год. Морские узлы: **I полугодие 2025**, EIA. Это годовые средние и исторические ориентиры, а не текущая телеметрия. В новом workbook EI 2026 дата торговой матрицы неоднозначна, поэтому использована явно датированная матрица из издания 2025.

## Локальный запуск

```sh
python3 -m http.server 8109
```

Открыть http://localhost:8109. Страница работает в любом подкаталоге. Выбранные страна, слой и морские узлы сохраняются в URL. CSV экспортирует полный срез независимо от фильтра таблицы; пропуски остаются пустыми.

## Воспроизводимость

Для пересборки нужен Python с `openpyxl`. Исходные Excel-файлы сохраняются локально в `data/raw`, но не включены в Git. Скрипт скачивает авторские workbook EI из публичных зеркал и проверяет фиксированные SHA-256; если содержимое поменялось, пересборка останавливается. Сведения об изданиях, таблицах, зеркалах и хешах — `data/raw/provenance.json`. Извлечённые запасы и ответы EIA сохранены в Git.

```sh
python3 scripts/build_data.py --canary
python3 scripts/build_data.py --canary --offline
# Только после сквозной проверки canary, включая публикацию:
python3 scripts/build_data.py
python3 scripts/build_data.py --offline
```

EIA использует публичный DEMO_KEY либо EIA_API_KEY из окружения. При просмотре сайта ключ не нужен. Срез 2025 фиксирован намеренно: обновление года требует явной проверки и изменения параметров. Код берёт **первый** столбец года, а не повторяющийся год в колонках роста или доли. Пропуски остаются null; нули остаются нулями; агрегаты не превращаются в страны. При неизвестном спросе баланс не рассчитывается.

Канадские нефтяные пески исключены из запасов OPEC; расчёт срока для Канады отключён. Срок при потреблении — грубое сопоставление запасов сырой нефти и спроса на нефть/нефтепродукты, не прогноз исчерпания или срок автономности. При добыче используется отдельный показатель сырой нефти с конденсатом EIA. Формулы: `запасы, млрд × 1000 / (скорость, млн/сутки × 365)`.

Торговля сохранена в исходных единицах. Объёмы разных проливов не складываются. Пунктир — схема морского коридора, а не трекинг танкеров. Линия Канада → США иллюстрирует трубопроводный коридор без количественной оценки. Карта показывает отдельно подписанные морские узлы; количественные торговые направления перечислены под картой.

## Проверки

```sh
python3 scripts/test_data.py
node scripts/smoke.cjs http://localhost:8109
```

UI-тест использует Playwright и отдельный headless Chrome. `PLAYWRIGHT_PACKAGE` задаёт путь к Playwright, `CHROME_CHANNEL` — канал браузера, `REPORT_DIR` — папку скриншотов. Проверяются выбор на карте, все слои, поиск на русском/английском/ISO, сохранение URL и перезагрузка, нули/пропуски, морские узлы, фильтры, CSV, мобильная ширина, отказ загрузки и отсутствие ошибок выполнения.

Сайт пока не содержит временного ряда. Данные отделены от интерфейса; история впоследствии добавляется отдельными годовыми срезами.
